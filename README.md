# 🧩 Quadro Kanban - feito em C#

Um sistema de gerenciamento de tarefas estilo **Kanban**, desenvolvido com **C# e Windows Forms**. Ideal para organizar atividades por status e prioridade de forma prática e visual. Cada tarefa é exibida em forma de card, com botões para atualizar, mover entre colunas e excluir.

## 📌 Funcionalidades

- ✅ **CRUD completo** (Criar, Listar, Atualizar, Deletar tarefas)
- 🎨 **Cards coloridos por prioridade** (Alta, Média, Baixa)
- 📊 **Colunas por status** (Fazer, Fazendo, Finalizado)
- 🔍 **Filtro de tarefas** por:
  - Status
  - Prioridade
  - Título
  - Data
- 📄 **Exportação de relatório estatístico em PDF**
  - Informações de status e prioridade
  - **Gerado em tempo real**, refletindo os dados mais atuais do sistema
- 🪟 **Interface amigável em Windows Forms**
